## (b) Terms I chose myself

- Hängemattennetze: as in the game's later line ("sechs Hängemattennetze").
- Anzug: as in ch02 to ch05 (the game uses Anzug for suits).
- verschleimt for "slimed" (the game has Schlick, Schlamm; no term for the eels' slime).
- Muschelschale for "shell" (the game uses Muschel for shell).
