## (b) Terms I chose myself

- slipways (plural) = die Hellingen (follows game "Hellingen")
- floodlights = Flutlichter
- girders = Träger; great square well = quadratischer Schacht
- cranes = Kräne; drawing tables = Zeichentische
- barges (in Lashing) = Kähne; trawlers = Trawler; houseboats = Hausboote; oil drums = Ölfässer; tubs = Zuber; stovepipes = Ofenrohre
- nightclothes = Nachthemden

## (c) Possible errors in the original (not fixed)

- Raske's long speech is split into two paragraphs; the first has no closing quotation mark (correct English convention). I kept the same in German: paragraph 45 has an opening „ without a closing “ on purpose.
- "Dace's aunt" and the fat old man appear without introduction in this chapter; presumably set up earlier.
