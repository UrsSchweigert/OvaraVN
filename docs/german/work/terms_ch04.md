# Chapter 4: terms

## Terms not in the glossary or decisions

| English | German | Reason |
|---|---|---|
| shelf (the rock ledge at the Well) | der Absatz | "Sims" is too small, "Bank" suggests a bench. Used about ten times |
| hospital (Lantern, Hush) | das Krankenhaus | plain word; "Hospital" would read as foreign |
| landing | die Anlegestelle | plain |
| box bed | das Kastenbett | the real German term |
| loft | der Dachboden | plain |
| still-room (Maelis's jar room) | die Vorratskammer | the text says only "where she kept her jars"; "Destillierstube" would add a fact. Uncertain |
| well-warden's squid | Tintenfische | Jef's gloss for "Brunnenwächter" |
| crawlway | der Kriechgang | plain |
| covered ways | die überdachten Gänge | plain |
| the works (of the heart) | das Werk | "in the works" = inside the mechanism |
| seat / reseat (a coupling) | einsetzen / wieder einsetzen | one verb for all uses: "seated wrong" = falsch eingesetzt, "I want it seated as it was meant to be" |
| clear it, seat it, or replace it | Freimachen, einsetzen oder ersetzen | Jef's three actions |
| Sorry (Maelis's one-word answer) | Reumütig | "Sorry" can be an apology or "full of regret". I took it as regret, because Jef's remorse is the point (the darts, Sounding). Uncertain: please check |
| hands like a pair of feet | Hände wie zwei Füße | literal |
| a pen-bump | eine Beule vom Stift | no good German word |
| Queen of the Stingrays (once) | Königin der Stachelrochen | glossary |
| "Nothing the sea is given" | Nichts, was der See gegeben wird | Maelis, a mariner, speaks of the sea as a person: die See |
| mend (as a plain verb: "mended round the edges", "half-mended things", "mended strap") | ausbessern / flicken / reparieren | only the craft level "Mend" and Jef's machine work is "instandsetzen / instand setzen"; plain repairs use plain words |
| "let nobody down who meant harm" (wardens) | keinen hinabgelassen, der Böses im Sinn hatte | read as "let nobody descend" |
| "Twenty-two years of one" (Anselm) | Zweiundzwanzig Jahre Investition | kept short and a little odd, like the English |
