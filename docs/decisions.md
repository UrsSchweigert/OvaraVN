## 2026-11-24: save sync off

`config.has_sync = False` in `game/game/options.rpy`. Ren'Py's default Save and Load screens show Upload Sync and Download Sync, which send saves to Ren'Py's public server (sync.renpy.org). The owner asked for them to be switched off, so the game has no upload feature and no privacy disclosure is needed for it. Keep it off.
- 2026-11-24: language switch. Preferences has "English" and "Deutsch" buttons (Ren'Py `Language()`, names not translated), and the main menu has a small "Language / Sprache" button that opens Preferences. First start only, a German device language starts the game in German, otherwise English; after that the player's choice is never overwritten (`persistent.vn_lang_initialised`). Device language: `VN_SYSLANG`, then `renpy.translation.detect_user_locale()`, then LANG variables. The developer switch `VN_LANG` saves and restores the player's choice (`persistent.vn_lang_saved`). Reason: German readers must find German without a dev flag, and a wrong guess must be easy to fix. Details: `docs/german/language-switch.md`. Ren'Py also reads `game/game/saves/persistent`, so tests of a fresh start need a copied project and an empty `HOME`.

## 2026-11-24: German ebook

- The German ebook is built from the German full text of the original novel, `work/german/ch01.md` to `ch18.md` (the cut passages were translated new from the English; the reviewed game wording was reused where the text is unchanged). The chapter files are never edited by the tools.
- `tools/assemble_german.py` joins the chapters into `work/german/novel_de.md` (title, part headings "Teil Eins: Angespült" and so on, chapters) and reports findings: dashes, straight quotes, unbalanced quotes and asterisks, heading mismatches, the invalid noun "Bewusstseinen" (left for the editor). It adds a comma after `?“` or `!“` before a lowercase speech tag and drops a trailing `---` that a chapter file may carry (a part separator copied from the English). It exits 1 on a missing chapter or a wrong heading; `--allow-missing` is for test builds. Chapter 18 keeps the title "Meet" (German decision 10), although glossary section F still lists "Begegnung".
- `tools/make_epub.py --lang de` builds the German EPUB (language `de`, "Kapitel N", "Teil Eins", closing "Ende", German copyright page and sample closing page, hyphenation on, own UID). The default `--lang en` output is unchanged (checked: byte-identical except the modified time stamp). Subtitle "Ein Roman aus Ovara" (glossary). `tools/make_cover.py --title-lines` sets the German cover title on the same art (`art/store/cover/cover_c.png`); the English cover is byte-identical.
- `tools/build_german_ebook.sh` runs everything and writes `publish/books/der-mann-den-die-flut-brachte(.epub, -leseprobe.epub)`, `cover_de.jpg` and `publish/apple-books-upload/book_de.epub, sample_de.epub, cover_de.jpg`. The author name is read from the English epub's metadata at run time; it is never printed or stored in a committed file. `publish/` stays gitignored.
- `tools/check_epub.py` checks structure and compares every chapter paragraph with the source markdown. EPUBCheck is NOT installed here, so it was not run; `check_epub.py` says so when it is missing. Apple Books import on a device has not been tested.
