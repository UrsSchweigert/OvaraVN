# Decisions

One dated line each, with the reason. Later sessions must respect these. The decisions taken before the first session are in the table at the top of `PLAN.md`.
- 2026-11-22: The fal key is stored under the variable name `FAL` in the owner's env file, not `FAL_KEY`. `./vn image` must accept `FAL` as well as `FAL_KEY` and `FAL_API_KEY`. Reason: that is what the file uses; the owner's file is not ours to change.
- 2026-11-22: Manifest format that `./vn check` expects: `work/manifest/chNN.json` is `{"scenes": [{"id": "c01.s01", "place", "time", "cast": [names], "mood", "key_moment"}, ...]}`, one entry per scene id; the merged cast list is `work/manifest/cast.json`, a list of names (or a dict keyed by name). Reason: the spec names the fields but not the layout; scene-analysts must write this layout.
- 2026-11-22: `./vn image` sends reference images as base64 data URIs in `image_urls`; verified with one real call to `fal-ai/flux-2/flash/edit` (it accepted them). Reason: no upload step needed. fal rejects reference images under 64x64 pixels.
- 2026-11-22: All five candidate models in `config/models.json` are edit models and need at least one `--ref`. For a first image with no reference, use a plain flat-colour placeholder or a text-to-image model added later. Prices were read from fal's pages on this date: nano-banana $0.0398, nano-banana-2 $0.08 (1K), seedream-4.5 $0.04, flux-2 $0.012/MP, flux-2-flash $0.005/MP. Recheck before the bake-off.
- 2026-11-22: A call fal rejects with HTTP 400, 401, 403, 404 or 422 is logged at cost 0; any other failure keeps its estimated cost in the ledger. Reason: a rejected request does no work; a timeout might have been billed.
- 2026-11-22: In `work/manifest/chNN.json`, `time` and `key_moment` must be present but may be null (the scene-analyst role says to write null where the text is silent). `place`, `cast` and `mood` must be non-empty. `./vn check` was changed to match; the first version wrongly treated null as missing. Owner: say if you would rather every scene had a time and a key moment.
- 2026-11-22: Merged cast list is `work/manifest/cast.json` (name, aliases, scene count, first scene), written by the lead. Wrack and Ilan Voss are one person (c07.s05: "His name was Ilan Voss"), listed as "Wrack" with aliases. Raske = Teodora Raske, Crane = Adler Crane, Rook and Anselm = Anselm Rook, Odo of Lashing = Odo, Vey = Elder Vey. `work/manifest/places.json` lists each place name the analysts used and its scenes; the 64 names still hold variants of the same place (for example nine "Low Anthem ..." names) and the art director merges them into backgrounds in stage 3.
- 2026-11-22: Where the text gives no time of day, the manifest `time` is null, or the light the text does state; never "not stated".
- 2026-11-22: Ren'Py 8.6.1 (build 8.6.1.26111705) and its iOS package Renios are installed at `/Users/ursschweigert/renpy/renpy-8.6.1-sdk` (path in ignored `config/local.json` as `renpy_sdk`). The owner told the lead to install it; downloaded from renpy.org/dl/8.6.1, sizes matched the server's. No checksum was compared. Lint run on the bundled sample game works: `renpy.sh <project> lint`. Still unverified: that this version builds for the current Xcode 27.2 and iOS (PLAN.md asks for this at stage 7).
- 2026-11-22: Sprite backgrounds are removed with `tools/cutout.py` (standard library only; flood fill from the border, edge softened). The art in `art/refs/` keeps its grey background as the reference; the copies in `game/game/images/` are cut out. Known flaw: bare background inside an enclosed gap (for example inside Davin's net) stays. Reason: no extra packages, no per-image cost, worked on all seven chapter 1 sprites.
- 2026-11-22: Backgrounds stay at the model's 1920x1088 and Ren'Py scales them to 1920x1080 (under 1% stretch).
- 2026-11-22: Moving backgrounds are in `game/game/effects.rpy`. Underwater backgrounds (kelp forest, terraces and dome, terrace work; the sea-door pool at half strength) get a very light ripple from a small shader, 40-second loop that returns exactly to its start, picture enlarged 1.2% so no edge shows. Sun rays (`show fx sunrays`) and rain (`show fx rain`) are overlays for scenes above the water; no chapter 1 scene needs them. Verified by having the game save its own frames at two moments (they differ; the rain and rays render). Not verified on a phone.
- 2026-11-22: `tools/cutout.py` also clears background seen through gaps inside the subject (between hair strands), only where the gap's colour matches the background and is grey, so eye whites and skin highlights stay. Test in `tools/tests/test_cutout.py`.
- 2026-11-22: Sprites and portraits are now cut out with fal's `birefnet-heavy` (fal-ai/birefnet/v2, model "General Use (Heavy)"), through `./vn image birefnet-heavy --ref in.png --out out.png --purpose sprite`. It returns a real RGBA PNG. Reason: the local `tools/cutout.py` cleared one eye white in Wrack's first portrait (it matched the background grey) and left light outlines around Sefa's hair; BiRefNet kept both clean. Bria RMBG 2.0 (`bria-rmbg`, $0.018) was also tested: same eye result, but faint grey outlines around hair strands. BiRefNet's page says $0 per compute second; the ledger books it at an estimated $0.01 per image. `tools/cutout.py` stays as a free fallback but must not be used on faces without checking the eyes at full size.
- 2026-11-22: Grey-background portraits are the references in `art/refs/ch01/portraits/`; the cut-out versions are in `art/refs/ch01/portraits_cut/` and are copied to `game/game/images/p_<name>.png`.
- 2026-11-22: Portraits are lit to match the scene. `game/game/effects.rpy` puts the portrait tags (`left`, `right`, `bother`) on their own layer "portraits"; that layer is tinted, darkened and desaturated per background (table `PORTRAIT_LIGHT`, keyed by the background's name; unknown backgrounds get no change), gets the same light ripple under water, and fades softly at the bottom. No story script change. To light a new background, add one line to `PORTRAIT_LIGHT`. Verified by having the game save frames (kelp forest, dry room, long hall); the tint values are fractions of 1 turned into 0-255 for Ren'Py.
