# Decisions

One dated line each, with the reason. Later sessions must respect these. The decisions taken before the first session are in the table at the top of `PLAN.md`.
- 2026-11-22: The fal key is stored under the variable name `FAL` in the owner's env file, not `FAL_KEY`. `./vn image` must accept `FAL` as well as `FAL_KEY` and `FAL_API_KEY`. Reason: that is what the file uses; the owner's file is not ours to change.
- 2026-11-22: Manifest format that `./vn check` expects: `work/manifest/chNN.json` is `{"scenes": [{"id": "c01.s01", "place", "time", "cast": [names], "mood", "key_moment"}, ...]}`, one entry per scene id; the merged cast list is `work/manifest/cast.json`, a list of names (or a dict keyed by name). Reason: the spec names the fields but not the layout; scene-analysts must write this layout.
- 2026-11-22: `./vn image` sends reference images as base64 data URIs in `image_urls`; verified with one real call to `fal-ai/flux-2/flash/edit` (it accepted them). Reason: no upload step needed. fal rejects reference images under 64x64 pixels.
- 2026-11-22: All five candidate models in `config/models.json` are edit models and need at least one `--ref`. For a first image with no reference, use a plain flat-colour placeholder or a text-to-image model added later. Prices were read from fal's pages on this date: nano-banana $0.0398, nano-banana-2 $0.08 (1K), seedream-4.5 $0.04, flux-2 $0.012/MP, flux-2-flash $0.005/MP. Recheck before the bake-off.
- 2026-11-22: A call fal rejects with HTTP 400, 401, 403, 404 or 422 is logged at cost 0; any other failure keeps its estimated cost in the ledger. Reason: a rejected request does no work; a timeout might have been billed.
- 2026-11-22: In `work/manifest/chNN.json`, `time` and `key_moment` must be present but may be null (the scene-analyst role says to write null where the text is silent). `place`, `cast` and `mood` must be non-empty. `./vn check` was changed to match; the first version wrongly treated null as missing. Owner: say if you would rather every scene had a time and a key moment.
- 2026-11-22: Merged cast list is `work/manifest/cast.json` (name, aliases, scene count, first scene), written by the lead. Wrack and Ilan Voss are one person (c07.s05: "His name was Ilan Voss"), listed as "Wrack" with aliases. Raske = Teodora Raske, Crane = Adler Crane, Rook and Anselm = Anselm Rook, Odo of Lashing = Odo, Vey = Elder Vey. `work/manifest/places.json` lists each place name the analysts used and its scenes; the 64 names still hold variants of the same place (for example nine "Low Anthem ..." names) and the art director merges them into backgrounds in stage 3.
- 2026-11-22: Where the text gives no time of day, the manifest `time` is null, or the light the text does state; never "not stated".
- 2026-11-22: Ren'Py 8.6.1 (build 8.6.1.26111705) and its iOS package Renios are installed at `/Users/ursschweigert/renpy/renpy-8.6.1-sdk` (path in ignored `config/local.json` as `renpy_sdk`).
